## Backend Security Audit Summary
- **Authentication**: JWT stateless authentication with role claims.
- **Role Isolation**: Strict URL patterns enforcing `BEEKEEPER`, `CUSTOMER`, `LAB`, `ADMIN`, `KVIC_OFFICER`.
- **Passswords**: Hashed using BCrypt.
- **DTO Safety**: Entity objects are never leaked directly over HTTP; sensitive credentials (passwords, JWT secrets, DB connection strings) are sanitized.
